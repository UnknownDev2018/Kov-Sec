# 🇷🇺 Kov-Sec — Защита Android APK от реверс-инжиниринга

**Сайт:** [https://kov-sec.com](https://kov-sec.com) | [🏠 Назад ко всем языкам](README.md)

**Kov-Sec** — это передовая платформа защиты Android APK. Она преобразует байт-код вашего приложения во внутреннюю виртуальную машину и применяет несколько уровней защиты от реверс-инжиниринга, взлома и модификации.

## Возможности
- **Целостность VM** — код приложения преобразуется во внутренний байт-код VM (многоуровневая защита)
- **Анти-хук** — блокирует FRIDA, Xposed, Zygisk, Substrate
- **Анти-отладка** — обнаруживает отладчики gdb/lldb/Android Studio
- **Анти-эмулятор** — обнаруживает BlueStacks, Nox, LDPlayer, Genymotion
- **Обнаружение Root** — обнаруживает Magisk, KernelSU, APatch, SuSFS, Shamiko
- **Проверка подписи** — предотвращает перепаковку с поддельными подписями
- **Обнаружение DEX-инъекций** — обнаруживает DEX, загруженные извне APK
- **Защита ADB** — блокирует доступ ADB
- **Инъекция библиотек** — обнаруживает внедрённые библиотеки
- **Удаление логов** — удаляет вызовы Log.* из DEX

## Форматы
**APK** (все пользователи) | **AAB** (VIP-пользователи)

## Архитектуры
arm64-v8a, armeabi-v7a, x86, x86_64

## Как начать
1. Посетите [https://kov-sec.com](https://kov-sec.com)
2. Загрузите APK или AAB
3. Выберите параметры защиты
4. Скачайте защищённый APK
