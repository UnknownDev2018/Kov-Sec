# 🇸🇦 Kov-Sec — حماية مكافحة الهندسة العكسية لتطبيقات APK

**الموقع:** [https://kov-sec.com](https://kov-sec.com) | [🏠 العودة لجميع اللغات](README.md)

**Kov-Sec** هي منصة متقدمة لحماية تطبيقات Android APK. تحول الكود الثنائي لتطبيقك إلى جهاز افتراضي داخلي وتطبق طبقات حماية متعددة ضد الهندسة العكسية والتلاعب والقرصنة.

## المميزات
- **سلامة VM** — تحويل كود التطبيق إلى كود VM داخلي (حماية متعددة الطبقات)
- **مكافحة الخطاف** — كشف وحظر FRIDA وXposed وZygisk وSubstrate
- **مكافحة التصحيح** — كشف مصححات gdb/lldb/Android Studio
- **مكافحة المحاكي** — كشف BlueStacks وNox وLDPlayer وGenymotion
- **كشف الروت** — كشف Magisk وKernelSU وAPatch وSuSFS وShamiko
- **التحقق من التوقيع** — منع إعادة التعبئة بتوقيعات مزيفة
- **كشف حقن DEX** — كشف DEX المحملة من خارج APK
- **حماية ADB** — حظر الوصول عبر ADB
- **كشف حقن المكتبات** — كشف المكتبات المحقونة
- **إزالة السجلات** — إزالة استدعاءات Log.* من DEX

## الصيغ المدعومة
**APK** (جميع المستخدمين) | **AAB** (مستخدمو VIP)

## البنى المدعومة
arm64-v8a, armeabi-v7a, x86, x86_64
